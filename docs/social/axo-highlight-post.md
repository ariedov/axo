# Аксо — «Щось хороше» (соцмережі)

Пост-фічер про запитання наприкінці повного дня.

**Картинки**

- `axo-highlight-4x5.png` — 1080×1350, крупний план діалогу, для стрічки.
- `axo-highlight-story.png` — 1179×2556, повний екран, для сторіс / Telegram.

**Alt-текст**

> Діалог Аксо «Щось хороше, що сталося сьогодні» з нотаткою «Перша годівничка для птахів!», кнопками «Пропустити» й «Зберегти» та рожевим аксолотлем.

**Текст поста**

Коли всі справи на день зроблено, Аксо не просто каже «молодець». Він питає: «Що доброго сталося сьогодні?» 💛

Відповідь зберігається в календарі. Через місяць можна перегорнути не лише галочки, а й справжні спогади: перша годівничка для птахів, вечір із бабусею, нова навичка.

Так звички стають не обов'язком, а приводом помітити хороше.

Батьки можуть вимкнути запитання в налаштуваннях. Усе — локально, без акаунтів і хмари.
